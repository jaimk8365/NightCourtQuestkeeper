## Interaction loop

1. Tap a glowing node to accept its short quest.
2. Complete the real-life action.
3. Tap the same node to mark it complete.
4. Receive XP, coins, affection and a brief celebration.
5. Save immediately.

## ADHD safeguards

- One task per node.
- Five nodes only in the vertical slice.
- Smallest-first recommendations.
- No loss of XP or affection.
- Duplicate completion cannot award twice.
- Focus sessions give proportional credit when ended early.
- Celebration is under 1.5 seconds.
